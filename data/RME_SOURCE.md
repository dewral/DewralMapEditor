# RME data provenance

The built-in DME material profiles were generated from:

- Repository: https://github.com/OTAcademy/RME
- Commit: `5b179c21ff5ae57ccefd1df97ff4264cac8b0340`
- Commit date: 2026-01-28
- Converter: `scripts/import-rme-data.py`

Generated files contain text material definitions only. CipSoft DAT/SPR files,
RME `items.otb` files, and client artwork are not copied.

## Tibia 15.11 / Canary profile (`1511`)

- Materials and `items.xml`: https://github.com/opentibiabr/remeres-map-editor
  (Canary's Map Editor, GPL-3.0-or-later), commit
  `533bb687a9f83a669d9fde44b47c4064a32d2c6d` (2026-11-02), folders
  `data/materials` and `data/items/items.xml`. Five source XML files contain a
  bare `&`; they were escaped before conversion. Converted with
  `scripts/import-rme-profile.py --lookid-is-item-id`, because Canary server ids
  are client ids.
- `creatures.xml`: names and outfits only, generated by
  `scripts/generate-canary-creatures.py` from
  https://github.com/opentibiabr/canary tag `v3.6.1`
  (`data-otservbr-global/monster` and `npc`).

No CipSoft files (appearances, sprite sheets, catalog) are part of this
profile. Point the 15.11 client profile at your own Tibia `assets` folder.
