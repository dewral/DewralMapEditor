# UI Colorize

In Fluent Dark, open **File → Preferences → Interface → UI Colorize**.

- Click a color row to briefly flash the corresponding editor elements.
- Use the color picker or enter a HEX color and click **Apply HEX**.
- Changes apply immediately and are saved in the application's settings.
- **Global blue accent** controls Lighting, selection borders, focused fields and primary actions until you override their individual colors. **Selection background** controls the subdued fill of active buttons, map tabs and selected palette cells.
- **Reset this color** removes its override; **Reset all colors** restores the defaults after confirmation.
- This editor changes Fluent Dark interface colors, not the map's sprites or lighting simulation.

The panel includes backgrounds, text, icons, buttons, hover and pressed states, borders, dividers, selections, scrollbars and the Lighting switch.
