# LZMA SDK subset

Unmodified public-domain C sources by Igor Pavlov from 7-Zip 24.09,
commit `e5431fa6f5505e385c6f9367260717e9c47dc2ee`:
https://github.com/ip7z/7zip/tree/24.09/C

The single-threaded encoder writes ObjectBuilder's LZMA1 Alone container.
The decoder is linked only into the export test. Each upstream file carries
its public-domain notice. No external compression executable is required.
