## Prompt

Create ONE high fidelity desktop application UI mockup for Dewral Map Editor, radically more minimal than a conventional complex level editor, inspired by restrained Windows 11 Qt Fluent WinUI 3 dark controls. Single screenshot 1920x1080 landscape, edge to edge application, no presentation headings, no second screenshot, no annotations, no device mockup. Use the reference only for authentic Tibia pixel art map content; redesign the chrome completely. Sophisticated quiet charcoal neutral colors, no navy, no gradients, no bright blue filled panels, no large cards, no redundant controls. 1px separators, 4px radius small controls, Segoe UI, soft gray icons. One subtle pale blue accent only for selected tool underline. About 83% of window is map canvas.
Layout exact:
top 34px minimal native title bar small DME icon and 'Dewral Map Editor' left, compact unobtrusive 'Search commands' centered, normal window controls right.
second row 34px menu File Edit Map Tools View Help left; far right small save icon and undo redo.
below that left palette occupies 208px width, full height; all rest canvas. No persistent right sidebar, no bottom drawer, no minimap overlay, no floating selection toolbar, no activity rail.
Canvas header just 34px two quiet file tabs 'forest.otbm •' 'cave.otbm', then small tool icons Draw Select Erase in a compact group right, tiny 'Floor 7' and '100%' dropdowns at far right. Main canvas stunning authentic crisp 2D top-down Tibia sprite map: open grassy landscape, winding dirt road, small timber outpost with fence, rocky cave edge, river and wooden bridge, scattered trees; spacious natural composition and readable tile detail not dense visual noise. No decorative graphics, no charts. A small brush cursor outline is enough.
Left palette: heading 'Terrain' with dropdown chevron, search field 'Search brushes', small text tabs 'All' 'Favorites', category dropdown 'Nature', then a compact 3-column grid of 48px tile previews with no individual card outlines on neutral dark background. Ground textures grass dirt gravel sand stone plus trees bushes rocks. Subtle small labels under tiles, no fake item IDs. Plenty of blank neutral space below grid; bottom of left panel a single small row 'Brush  3' with compact size field and shape icon, then 'Auto border' native small on toggle. Footer 24px under canvas coordinates '1185, 1163, 7' left, 'Saved' right. ALL other features accessible through menus, command search and on-demand panes, not shown all at once. Overall feel: minimalist serious native desktop creation tool, no dashboard or website look. Keep precise typography and calm chrome, map dominates.
