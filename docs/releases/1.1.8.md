# Dewral Map Editor 1.1.8

## Changes

- Restore cached lighting immediately when switching floors. Previously, the
  shared GPU texture could retain another floor's lighting until pan or zoom.
- Match OTEditor's window appearance with native Windows 11 rounded corners,
  a dark system frame and a visible, subtle 1-pixel gray outline in Fluent Dark.
  Maximized and fullscreen windows omit the custom outline. Native Snap,
  maximize interaction and resize controls are retained.
- Move the entire Fluent Dark palette by its header, dock it to the left or
  right, or keep it floating inside the editor. Blue docking previews follow
  the panel edge. Resize and lock the panel; its layout is saved between sessions.
- Close the palette with × and restore it with View → Show palette or Ctrl+B.
  Hiding a docked palette gives its space back to the map.
- Reject trailing OTBM data and text longer than 65,535 encoded bytes. Failed
  saves preserve the existing map; reserved marker bytes survive save/load.
- Include the independent binary/DAT readers and DME lighting grid sampler.
- Retain version 1.1.7 improvements: brush manager invisible-sprite filtering,
  tileset membership indicators and type-to-select dropdowns.

## Download

Use **DewralMapEditor-windows-x64.zip** for the complete Windows application.
Extract the entire archive; do not replace only DME.exe. Client assets are not
included. **DewralMapEditor-source.zip** contains the corresponding source.
Checksums are available in **SHA256SUMS.txt**.

Version 1.1.8 is newer than 1.1.7, so installed copies can detect it through the
updated manifest after publication completes.

## Validation

- Windows application compiled with Qt 6.10.2 / MinGW x64.
- Native window tests passed at normal and scaled DPI.
- Light sampling and OpenGL/Direct3D 11 rendering/readback tests passed.
- OTBM storage, editing, background loading, house/zone integration and recovery
  suites passed using generated fixtures.
- Palette docking checks and the offscreen startup smoke test passed.

The existing AdvancedBrushEditor duplicate-method warning is still present.
